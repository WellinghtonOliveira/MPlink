# Projeto Pessoal – Plataforma Web para Extração de Áudio

Um dos primeiros projetos desenvolvidos e publicados de forma independente, consistindo em um **site web criado e lançado integralmente por mim**, desde o desenvolvimento até a disponibilização.

O projeto tem como objetivo permitir a **extração de áudio a partir de vídeos**, com foco no aprendizado prático de **desenvolvimento web**, integração de funcionalidades, tratamento de entradas do usuário e estruturação de uma aplicação funcional do início ao fim.

Este projeto foi fundamental para o desenvolvimento da autonomia técnica, compreensão do ciclo completo de criação de um produto e consolidação de conhecimentos práticos em programação e publicação de aplicações web.
